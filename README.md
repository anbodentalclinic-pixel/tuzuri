# つづりと発音

音とつづりの関係を、3Dトロッコのタイピングで練習するゲーム（パソコン向け）。

## まちがい記録との同期（版 10/29-sync）

- 起動したとき、Google スプレッドシート「拓真 英語まちがい記録」から苦手な単語を読み込み、「苦手な単語」に加えます（ワークやテスト、本文JUMPでまちがえた単語も入ります）。
- 初めてこの版を開いたときだけ、パソコンに残っていた苦手な単語をスプレッドシートに送ります。
- トロッコを走るたびに、単語ごとの結果（× まちがい／○ 正解）を送ります。
- ホーム画面の下に「版 10/29-sync　まちがい記録：スプレッドシートと同期ずみ」と出れば、読み込みができています。
- 送るのは単語・答え・日時だけで、名前は送りません。

## 線路の修理（文法）（版 10/29-repair）

- スプレッドシートの「文法」の苦手（本文JUMP・ワーク・テストでまちがえたもの）の数だけ、線路がこわれた状態でホーム画面に出ます。
- 「修理に出発」で、苦手な文法の問題が出ます（1回最大12問）。分かれ道の2つの看板から正しい形を打つと1区間直り、スプレッドシートの苦手度も1つ減ります。まちがえると苦手度が1つ増えます。
- 文法の答えはスペースや ' （アポストロフィ）も打ちます。play と plays のように片方がもう片方の頭と同じときは、打ち終わったら Enter で決定します。
- 対応している文法：s のつけ方／doesn't のあとは元の形／疑問文の語順／Yes・No の答え方／語順／him・her・them／Why・Because／There is・are／How・By

## 景色・音楽・トラップ（版 10/29-world）

- Program ごとに景色と音楽が変わります。Program 4＝日本の町（和音階）、Program 5＝アメリカの町（ポップス）、Program 6＝サバンナ（打楽器）、Program 7＝オーストラリア（低いうなり音＋明るい旋律）、つづりのルール＝谷。
- 全単語・苦手な単語・線路の修理では、1問ごとにその単語や文法の Program の景色に切りかわります。
- トラップの種類は苦手度で決まり、出るかどうかはランダムです（版 10/29-trap2）。どのモードでも、苦手な単語・文法にだけ出ます。
  - カラス（苦手度1〜2、出る確率 約35%）：飛んできて、打てる時間が短くなる
  - 強い風（苦手度3、約50%）：看板の文字の一部が飛ばされて見えなくなる
  - 悪魔（苦手度4以上、約60%、1回に1体まで）：線路をふさぐ。2問続けて正解するとたおせる。2体目からは強い風になる
  - 脱線した直後の問題と、トラップの直後の問題には出ない
- 正解すると火花、脱線すると土煙が出ます。画面が重いパソコンでは、自動で影や描き込みを減らします。

## ボクセルのジオラマ風グラフィック（版 10/29-voxel）

- 景色を、小さな立方体を積み重ねたジオラマ風に作り直しました。線路は浮かぶ島の上を走り、島の端の向こうは暗い背景になります。
- 木・岩・家・動物・人・トロッコ・カラス・悪魔も、すべて立方体で組み立てています。町の人や動物は島の上を歩き回ります。
- 雪（谷）、桜の花びら（日本の町）、砂ぼこり（サバンナ）が舞います。
- カメラはななめ上から見下ろす位置にしました。分かれ道の看板は、いつもカメラのほうを向きます。

## 谷の上の高架（版 10/29-valley）

- 線路を、谷の上にかかる木の高架にもどしました（ボクセルの見た目はそのまま）。
- 谷底には川が流れ、家・木・動物は谷底にあります。谷底からそびえる岩の柱の上にも、木や鳥居などがのっています。

## 音楽のトラック（版 10/29-music）

各曲を、メロディ・合いの手・和音・ベース・ドラム・打楽器2の6トラックにしました（オーストラリアはうなり音を加えた7トラック）。
景色ごとに楽器を変えています：谷＝ピコピコ音、日本の町＝琴と笛と拍子木、アメリカの町＝ギターとオルガンと手拍子、サバンナ＝マリンバとボンゴとシェイカー、オーストラリア＝笛とマリンバと拍子木、悪魔＝とがった音の和音と手拍子。

## 保護者おためしモード（版 10/29-trial）

- ホーム（マップ）画面の下の「保護者おためしモード」を2秒長押しするとオンになります。もう一度2秒長押しするとオフです。
- オンの間は、スプレッドシートに記録を送らず、星・ベスト記録・苦手な単語・線路の修理などの記録も変えません。画面に「（おためし）」と出ます。
- 消し忘れても、60分たつと自動でオフになります。
