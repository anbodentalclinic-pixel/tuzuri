# つづりと発音

英語のつづりと発音の関係を、3Dのトロッコゲームで身につける（中学1年向け）。

## 遊び方
- パソコンのブラウザ（Chrome / Edge）で開く
- 谷にかかった線路をトロッコで進む。分かれ道の看板に、正しいつづりとまちがえたつづりが出る
- 単語の音声を聞いて、正しいつづりを打つ。打ち切るとトロッコが加速して正しい線路へ進む
- まちがえたつづりを打つと、ポイントが切りかわって途切れた線路へ進み、脱線する
- 分かれ道に着くまでに打ち切れなくても脱線する
- トロッコは3台。全部脱線したら終了
- スペースキーで、もう一度音声を聞ける。Esc でステージ選択にもどる
- 効果音とBGMは画面右上のボタンでそれぞれオン／オフできる
- BGMはオリジナル曲。分かれ道が近づくとテンポが上がる。単語の読み上げ中は音量が下がる
- パソコンではキーを直接読み取るので、日本語入力がオンのままでも打てる
- 3D表示には three.js（cdnjs から読み込み）を使っている。ネット接続が必要

## ステージ
単語は教科書 Program 4〜7（テスト範囲）の本文・New Words から、ルールに当てはまるものを選んでいる。

1. u の「ア」（lunch, uncle, hungry, custard …）
2. th の音（thank, something, their, brother …）
3. i の「アイ」（like, right, island, fried …）
4. 「イー」は ea か ee（eat, meat, teacher, sweet, deep … 例外として ready）
5. r と l（really, rich, reef, land, legend, library …）
6. まとめ（全ステージからランダム10問）

分かれ道のまちがいのつづりは、カタカナ発音のまま書いた形にそろえている
（lanch, sank, zis, rait, miit, rady など）。

## 教科書の全単語
ホーム画面の下半分。Program 4〜7 の New Words（人名・地名・2語以上の語句・短縮形を除く129語）を出題する。
- Program 4／5／6／7：そのプログラムの単語からランダムに10問
- Program 4〜7 ぜんぶ：全単語からランダムに10問
- 苦手な単語：どのステージでも、まちがえた単語がたまる。正しく進むたびに減っていき、0になると消える

各ステージのベスト記録（何問正しく進んだか）はブラウザに保存される。

## 公開方法（GitHub Pages）
1. 新しいリポジトリを作り、このzipの中身（index.html, icon.png, .nojekyll, README.md）をアップロード
2. Settings → Pages → Branch を main / root にして保存
3. 1〜2分後に `https://(ユーザー名).github.io/(リポジトリ名)/` で開ける

## 単語の入れ替え
index.html の `STAGES` の `words` を書きかえる。
形式は `['単語','意味','色をつける部分']`（ea ステージは4つ目に読み「エ」「イー」）。
教科書の全単語は `TEXTBOOK` に `['単語','意味']` の形で入っている。
分かれ道に出すまちがいのつづりは `WRONG`（全単語用は `TB_WRONG`）に `単語:'まちがい'` の形で追加する。
